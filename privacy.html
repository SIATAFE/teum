틈(TEUM) 개인정보처리방침

시행일: 2026년 10월 1일

틈은 개인용 영어 학습 앱입니다. 앱을 만든 사람은 사용자의 정보를 수집하거나 따로 보관하는 서버를 운영하지 않습니다.

1. 앱이 다루는 정보

  • 학습 기록: 카드 평가, 오답노트, 내가 추가한 단어, 필기, 읽던 위치. 기기 안과 사용자의 iCloud(Apple의 개인 저장소)에만 저장됩니다.
  • 구글 계정(연동을 켠 경우에만): 연결한 계정의 이메일 주소(설정 화면에 어떤 계정이 연결됐는지 보여 주는 용도)와, 앱이 사용자의 구글 드라이브에 만든 ‘틈 오답노트’ 시트 파일.
  • 받는 메일 주소(엑셀로 메일 보내기를 쓸 때만): 사용자가 설정에 적은 주소. 기기에만 저장됩니다.

2. 구글 사용자 데이터를 쓰는 방법

  • 앱은 drive.file 권한을 사용합니다. 즉 앱이 직접 만든 시트 파일에만 접근하고, 드라이브의 다른 파일은 보거나 바꿀 수 없습니다.
  • 사용자가 ‘엑셀로 메일 보내기’를 처음 누를 때만 gmail.send(Gmail로 메일 보내기) 권한을 추가로 요청합니다. 이 권한으로는 사용자가 버튼을 누를 때마다 ‘틈 오답노트’ 시트를 엑셀 파일로 바꿔, 사용자가 적은 주소로 메일 한 통을 보내는 일만 합니다. 메일함을 읽거나 다른 메일을 보내지 않습니다.
  • 그 시트에 오답노트(단어·뜻·예문·보기)를 쓰고, 사용자가 시트에서 고른 평가와 답을 읽어 앱의 학습 기록에 합칩니다.
  • 구글에서 받은 정보는 이 목적 말고는 쓰지 않으며, 누구에게도 팔거나 넘기지 않고, 광고에 쓰지 않습니다.
  • 로그인 권한(토큰)은 사용자의 기기 키체인에만 저장되고 다른 곳으로 보내지 않습니다.
  • 틈이 구글 API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 보관과 삭제

  • 시트는 사용자의 구글 드라이브에 있으므로 사용자가 언제든 지울 수 있습니다.
  • 앱 설정의 ‘구글 연결 끊기’를 누르면 기기에서 로그인 권한을 지우고 구글에 권한 취소를 요청합니다. 구글 계정 → 서드파티 앱 액세스에서도 직접 끊을 수 있습니다.
  • 학습 기록은 앱을 지우거나 iCloud 설정에서 지울 수 있습니다.
